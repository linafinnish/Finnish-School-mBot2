# Finnish School mBot2

## What Is mBot2?

mBot2 is an **educational robot** that helps students learn programming and robotics. We use it in ICT lessons to understand how robots work.

## What Can mBot2 Do?

mBot2 can:
- Move forward and backward.
- Turn left and right.
- Detect obstacles using sensors.
- Display text on its screen.
- Show different colours using RGB LEDs.

## What Is CyberPi?

CyberPi is the main controller of mBot2. It has a screen, buttons, sensors and a microphone. We can program it using Python and mBlock.

## Three Important Features of mBot2

1. CyberPi screen for displaying information.
2. Sensors for detecting obstacles.
3. RGB LED lights for displaying colours.

## Why Do We Use mBot2 in ICT?

We use mBot2 to learn **Python programming** and understand how robots follow commands.

*I think mBot2 makes learning programming more interesting because we can see how our instructions work.*
